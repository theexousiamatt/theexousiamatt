# AstroPSD website

Responsive static portfolio built from the Figma reference for AstroPSD, a motion designer.

## Pages
- Home: /index.html (hero, client logo strip, testimonial and footer)
- Portfolio: /portfolio.html (two-column desktop / single-column mobile)

## Assets
Original landscape image, client logos, testimonial portrait and CTA icons are exported from the supplied Figma file into /assets.

## Before public client launch
1. Replace the grey portfolio media placeholders with Astro's actual video thumbnails and video files / embeds.
2. Set Astro's verified booking link, X link and LinkedIn link in script.js under SETTINGS.
3. Confirm the testimonial has publication approval.
4. Check original brand font licensing if you want exact Gazpol/Geist Serif typefaces; this build uses common font fallbacks.

The site is standalone HTML/CSS/JS. No Node runtime is needed. Both themes are built in, and reduce-motion accessibility settings are respected.
